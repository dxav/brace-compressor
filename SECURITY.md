# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.
Instead, use GitHub's private security advisory workflow for the repository or
contact the maintainers privately through the GitHub project page.

Include the affected version, reproduction steps, and any relevant logs or
sample payloads. Do not include secrets in reports.

## Scope

The codec validates container lengths, checksums, model versions, shapes, and
error bounds. Reports involving malformed containers, decompression resource
use, dependency vulnerabilities, or accidental data disclosure are welcome.
