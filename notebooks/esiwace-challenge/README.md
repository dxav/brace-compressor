# ESiWACE Challenge

This directory contains the BRACE implementation of the ESiWACE missing-values compression challenge.

The notebook is derived from the original challenge notebook in the `compression-lab-notebooks` repository:

- [Original notebook](https://github.com/igonzal-bsc/compression-lab-notebooks/blob/a00d8025c1f6a64d77a126ad31966adce5d957d8/04-challenges/01-nan-missing-values.ipynb)
- [Original repository](https://github.com/igonzal-bsc/compression-lab-notebooks)

The compressor configuration is the only challenge-specific part adapted for BRACE. The reference plotting and remote-dataset helper is loaded from the pinned upstream commit at notebook runtime.
